# 外部データの作業領域

`source_catalog.yaml` は取得先、提供量、変換形式、利用条件の確認項目をまとめた台帳です。通常分析は指定されたローカル証拠を読み、取得は `acquire` の明示操作で行います。

| 置き場所 | 内容 |
|---|---|
| `source_catalog.yaml` | 配布する取得先台帳 |
| `raw/`、`manifests/` | ローカルで取得した原本、取得情報とハッシュ |
| `snapshots/` | 変換した記録と対応する原本・数表 |

原本・取得結果を配布する場合は、各記録の出典と条件を確認してください。コマンド、対応する取得形式、照合・採用は[取得・照合・採用](../docs/data_sources.md)、出典とnoticeは[収録データと配布条件](../docs/source_license_policy.md)を参照してください。
