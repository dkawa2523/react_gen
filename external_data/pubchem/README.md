# PubChem External Snapshots

This directory is for reviewed PubChem-derived local snapshots created by
external tooling. PubChem support in this repository is intended for species
identity metadata only: formulas, names, synonyms, CIDs, SMILES, and InChIKeys.

PubChem is not a plasma reaction database. Do not treat PubChem identity
snapshots as experimental plasma reaction data, electron collision cross
sections, ion-neutral reaction networks, or validated plasma chemistry rates.

Snapshots generated by `external_data_tools.pubchem_fetch` should be reviewed
before they are used by prepare/enrich workflows. They must not be promoted into
the curated `registry/` automatically.
