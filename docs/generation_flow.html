reactgen / discover / acquire

入力ガスから反応式・状態リストまで

ガス名を受け取ってから反応式リストと状態リストを書き出すまでに、どの処理がどのデータを使って 何を判定しているか。判定点はインディゴ、データ源はティール、 棄却は赤で示します。

00目的

ガス名を入力し、妥当かつ網羅的な化学種リストと反応式リストを出力する。 多段(生成物のさらなる反応まで)で、イオンと励起状態を含みます。存在量と速度係数は 意図的に後回しで、この出力が DNT+ の計算対象を決めます。 

rgen generate  cases/ar_o2/case.yaml       # レジストリのみ。候補生成なし
discover network --gas Ar --gas CF4        # レジストリ + 候補生成
acquire asd Ar O F  →  rgen ingest  →  --overlay work/levels   # 外部データの取り込み

01データ源

レジストリはファイル群、オーバーレイはメモリ上でマージされます。curated なファイルは書き換えません。

場所持っているもの
registry/species/ 組成・電荷・state(kind / label / energy_eV / resolution / members)・properties・NASA多項式
registry/reactions/ 族ごとのチャンネル(type, threshold_eV, datasets, status)と、ペアの potential
registry/materials/表面材料と付着係数
registry/datasets/断面積表、速度係数
overlay(任意)rgen ingest が受理したもの。熱化学、原子準位など

射影 — 候補生成がレジストリを引く見方

view返すもの出どころ
known()(組成, 電荷) → 種ID全種。基底状態を優先
ionization()種 → IE [eV]プロパティ、無ければ電離反応の閾値。励起状態は IE(X)−E で導出
affinity()種 → EA [eV]electron_affinity_eV
enthalpy()種 → ΔHf [eV]プロパティ。励起状態は Hf(X)+E で導出
excitation()種 → {metastable / resonant / lumped: eV}NIST ASD 由来
基底状態の優先が要ります。 O と O_1D は組成も電荷も同じです。 索引が後勝ちだと断片の命名が励起状態を拾い、e + SO → e + O_1D + S を生成します。

励起状態の値は導出です。 Hf(X*) = Hf(X) + E、IE(X*) = IE(X) − E。推定ではなく恒等式で、 導出した IE(Ar_4s) = 4.16 eV はレジストリの独立した実測閾値と一致します。

05判定レイヤー

何を根拠にその反応がリストにあるのかを、4つの別々の問いとして記録します。 1つの「信頼度」にまとめると、熱化学的に確実だが誰も述べていない反応と、 出典はあるが速度が未測定の反応が区別できなくなります。

レイヤー問い答えの種類
structureこの種は存在しうるか、式は保存するか conserved / conserved, species proposed
thermochemistryエネルギー的に開いているか exothermic by N eV / endothermic by N eV / unknown
kineticsこの条件で効くほど速いか fast / comparable / slow / negligible / unknown
attestation出典がこの反応を述べているか 出典名 / unattested
not_run と unknown は別の答えです。 前者は「そのレイヤーを評価していない」、後者は「評価したが判定できない」。 --layers structure,thermochemistry のように選ぶと、残りは not_run になります。

① 未登録の種が式に含まれる                      → 棄却
② |Σq(反応物) − Σq(生成物)| > 1e-9              → 棄却  ※表面反応は免除
③ 各元素で Σ n·count が一致しない                → 棄却

判定式の詳細 — レイヤーごと

各式は TeX と可読形の両方で示します。CSP により数式レンダラを読み込めないため、 TeX はそのまま引用できる形で置いています。記号の定義は末尾の物性表にあります。

レイヤー 1  structure — この種は存在しうるか、式は保存するか

1-1 電荷保存(全反応、例外なし。表面反応のみ免除)

\sum_i \nu_i q_i \;=\; \sum_j \nu_j q_j
      \qquad \text{棄却条件:}\quad \left| \sum_i \nu_i q_i - \sum_j \nu_j q_j \right| > 10^{-9}

可読形:  Σ νᵢqᵢ (反応物) = Σ νⱼqⱼ (生成物)

νは化学量論係数、qは電荷数。表面反応を免除するのは壁が電荷を吸収するためで、 気相の生成物だけを書くという表記上の約束に対応します。

1-2 元素保存

\forall E:\quad \sum_i \nu_i n_{E,i} \;=\; \sum_j \nu_j n_{E,j}

可読形:  各元素 E について  Σ νᵢ n_E,ᵢ = Σ νⱼ n_E,ⱼ

nE,i は種 i に含まれる元素 E の原子数。質量は別途検査しません — 元素組成が一致すれば質量は自動的に一致するためです。

1-3 価数(骨格が配位子を担えるか)(重粒子衝突の生成物に適用)

N_{\text{ligand}} \;\le\; \sum_{k \in \text{skeleton}} \nu_k V_k \;-\; 2\,(m - 1)

可読形:  配位子数 ≤ Σ(骨格原子の価数) − 2×(骨格原子数 − 1)

Vk は元素の価数(C=4, Si=4, S=6, N=3, O=2, ハロゲン=1)、m は骨格原子数。 第2項は骨格内の結合が消費する手の数(非環状飽和の上限)です。これにより CF5(4 < 5)、C2F7(2·4−2=6 < 7)、F3 が棄却されます。 環状構造には保守的で、環があれば実際の容量はこれより小さくなります。

1-4 陰イオンの存在(付着チャンネル)

\text{親陰イオン } A^- \text{ を書く} \iff EA(A) > 0

可読形:  EA > 0 のときのみ A⁻ を生成

EA は電子親和力。負なら束縛状態が無く、e + Ar → Ar⁻ は 遅い反応ではなく起こらない反応です。EA が未取得の種では判定できないため、 付着族は既定で切っています。

1-5 準安定の選別(原子の励起状態)

\text{E1 遷移 } |i\rangle \to |f\rangle \text{ が許容}
  \iff \pi_i \neq \pi_f \;\wedge\; |\Delta J| \le 1 \;\wedge\; \neg(J_i = J_f = 0)

\text{準安定} \iff \forall f \text{ with } E_f < E_i:\ \text{E1 遷移が禁制}

可読形:  下位の全準位への電気双極子遷移が禁制なら準安定

πはパリティ、J は全角運動量。基底状態だけでなく下位の全準位を見るのが要点です。 基底へのパリティ選択則だけで判定すると Ar の準安定が305個になりますが、 正しくは2個(11.548 eV の 3P2 と 11.723 eV の 3P0)。 基底項の微細構造は同一種として除外します。

レイヤー 2  thermochemistry — エネルギー的に開いているか

2-1 反応エンタルピー(統合式)

\Delta H \;=\; \sum_j \nu_j \Delta_f H_j \;-\; \sum_i \nu_i \Delta_f H_i

\Delta_f H(A^{+}) = \Delta_f H(A) + IE(A)
\Delta_f H(A^{-}) = \Delta_f H(A) - EA(A)

可読形:  ΔH = Σ生成物の生成エンタルピー − Σ反応物の生成エンタルピー

符号規約:ΔH > 0 が吸熱。イオンの生成エンタルピーは別の測定ではなく、 中性から電子を1つ外す(または束縛する)コストで決まる恒等式です。

2-2 相殺(実装上の要点)

\Delta H \;=\; \underbrace{\sum_s c_s \, \Delta_f H_s}_{\text{骨格の差}} \;+\; \underbrace{\sum_p \sigma_p \, \Delta_p}_{\text{荷電のコスト}},
\qquad c_s = \sum_{\text{prod}} \nu - \sum_{\text{react}} \nu

\text{if } c_s = 0 \text{ then } \Delta_f H_s \text{ は参照しない}

両辺に同数現れる骨格は係数がゼロになり、その値を引かずに消えます。 絶対エンタルピーを先に評価すると答えに影響しないデータを要求し、解ける反応を落とします。

2-3 特殊解(上式から導出され、手書きしていません)

\text{電荷交換 } A^+ + B \to A + B^+:
  \Delta H = \bigl[\Delta_f H_A + \Delta_f H_B + IE_B\bigr] - \bigl[\Delta_f H_A + IE_A + \Delta_f H_B\bigr] = IE_B - IE_A

\text{解離性電荷交換 } A^+ + BC \to A + B^+ + C:
  \Delta H = IE_B - IE_A + D_0(B\!-\!C)

\text{相互中和 } A^+ + B^- \to A + B:
  \Delta H = EA_B - IE_A

\text{Penning } M^* + X \to M + X^+ + e:
  \Delta E = IE_X - E_{\text{exc}}(M^*)

\text{解離極限 } e + AB \to e + A + B^*:
  \Delta E = D_0(A\!-\!B) + E^*(B)

D0 は結合解離エネルギーで、D₀(B−C) = ΔfH(B) + ΔfH(C) − ΔfH(BC) として 生成エンタルピーから求めます。電荷交換では ΔfH が完全に相殺するため、 生成エンタルピーが未知でも IE だけで解けます。

2-4 篩と閾値

\text{採用条件(重粒子):}\quad \Delta H \le E_{\max} = 2.0\ \text{eV}
\text{記録する閾値:}\quad E_{\text{th}} = \max(0, \Delta H)
\text{中性間の判定:}\quad \Delta H < -0.25\ \text{eV} \Rightarrow \text{open},\quad
                          \Delta H > +0.25\ \text{eV} \Rightarrow \text{closed}
\text{電荷交換の判定:}\quad \Delta E < +0.1\ \text{eV} \Rightarrow \text{open}

2.0 eV の根拠: 400 K で kBT = 0.0345 eV。バルクのイオンは熱的なので 2 eV 上のチャンネルには届かず、届くのはプレシースで加速されたイオンです。
0.25 eV の根拠: 約 7 kBT。見えない活性化障壁の代わりで、 わずかに発熱なだけの引き抜き反応は通常障壁を持つため、意図的に厳しくしています。
0.1 eV の根拠: 近共鳴電荷交換は最も速い領域なので、 この幅は「捨てる」ためではなく「符号が確定しない」幅です。ここでは open 側に倒します。
電子衝突には篩をかけません。 電子は必要なエネルギーを持ち込めるので、 可否ではなく閾値の問題になります。

2-5 解離極限が下限である理由

E_{\text{th}}^{\text{observed}} \;\ge\; \Delta E^{\text{adiabatic}} = D_0 + E^*

例: e + O_2 \to e + O + O(^1D)
    計算 7.13\ \text{eV} \quad\text{vs}\quad 実測 8.57\ \text{eV}\quad (\text{差 } 1.44)

差は垂直遷移と断熱極限の差(Franck–Condon)。計算値は threshold_eV ではなく delta_e_eV に記録し、 実測閾値が入ったときに 2-6 の検査が働くようにしています。

2-6 整合検査(blocking)

E_{\text{th}} \;\ge\; \Delta E - 0.05\ \text{eV} \qquad (\Delta E > 0 \text{ のとき})
E_{\text{th}}^{\text{excitation}} \;<\; IE(\text{target})
\bigl| E_{\text{th}}^{\text{ionization}} - IE \bigr| \;\le\; 0.05\ \text{eV}

3番目は独立した出典どうしの検算です。閾値は LXCat・文献、IE は mendeleev から来ており、 電離10反応で残差 0.022 eV 以下。偶然ではなく関係式が厳密に成立している証拠です。

レイヤー 3  kinetics — この条件で効くほど速いか

3-1 Langevin 捕獲率(イオン中性、無極性標的)

k_L \;=\; 2\pi q \sqrt{\frac{\alpha}{4\pi\varepsilon_0\,\mu}}
     \;=\; 2.342\times10^{-15}\,\sqrt{\frac{\alpha[\text{Å}^3]}{\mu[\text{amu}]}}\ \ \text{m}^3/\text{s}

\mu = \frac{m_1 m_2}{m_1 + m_2}

αは標的の分極率、μは換算質量。温度に依存しないのが Langevin 率の特徴で、 誘起双極子ポテンシャル −αq²/(2(4πε₀)²r⁴) による捕獲断面積が 1/v に比例するためです。 検算:Ar⁺/Ar で 6.7×10⁻¹⁶ m³/s。永久双極子を持つ標的では ion–dipole 式に切り替えます。

3-2 電子速度と率係数

v_e(E) = \sqrt{\frac{2E}{m_e}} = 5.9309\times10^{5}\,\sqrt{E[\text{eV}]}\ \ \text{m/s}

k(T_e) = \int_0^\infty \sigma(E)\, v_e(E)\, f(E; T_e)\, dE
       \qquad f = \text{Maxwell–Boltzmann}

断面積 σ(E) がある反応のみ評価できます。現在ほぼ全件が unknown なのは、 断面積が未取得であることと electron_density_m3 が未設定であることの両方によります。

3-3 壁損失頻度

\nu_{\text{wall}} = \gamma \,\frac{\bar v}{4}\,\frac{A}{V},
\qquad \bar v = \sqrt{\frac{8 k_B T_g}{\pi m}}

可読形:  ν = 付着係数 × 平均熱速度/4 × 表面積/体積

γは材料ごとの付着係数。v̄/4 は単位面積あたりの壁への流束(Hertz–Knudsen)。 volume_m3 と surface_area_m2 の両方が必要です。

3-4 関連度の判定

\nu_{\text{upper}} = k \prod_i n_i \quad(\text{片側上限})
\text{基準} = \tau_{\text{residence}}^{-1}\ \text{または最速反応}
\text{閾値} = 1/3\ \text{桁}(\text{物理基準})\ /\ 3, 6\ \text{桁}(\text{順序のみ})

存在量 ni が要ります。上限であって推定ではありません — 「これより速くはならない」だけを言い、遅いことの証明には使えます。

レイヤー 4  attestation — 出典が述べているか

4-1 照合(数式ではなく集合演算)

\text{attested}(r) \iff
   \bigl(\text{source\_type}(r) \notin \mathcal{D}\bigr) \;\vee\; \bigl(\text{sig}(r) \in \mathcal{K}\bigr)

\mathcal{D} = \{\text{bond\_breaking, formation\_enthalpy, dissociation\_limit,}
      \text{ionization\_and\_bond\_energy, vibrational\_manifold, structural}\}

\text{sig}(r) = \bigl(\text{family},\ \text{third\_body},\ \text{surface},\
                \textstyle\sum\nu\ \text{per species 両辺}\bigr)

𝒟 は本コードが自分で導出したものの集合で、自分自身の証拠にはなりません。 𝒦 は --known で渡した索引。照合は種ごとに係数を合算した化学量論で行うので、 2 e と e + e は同一と判定されます。 ラベルであってフィルタではありません — 沈黙は否定ではないので何も除きません。

07DNT+ への引き渡し

イオン衝突の断面積は外部データベースにありません。だから DNT+ が計算します。 本コードの役割は何を計算すべきかを決めることです。

ペアは反応式ではなく種から列挙します。 反応式が既にあるペアだけを渡すと、データが無いペア — つまり計算が必要なまさにそれ — が 指示書から漏れます。イオンと中性が出会えば、化学変化の有無に関わらず弾性散乱と捕獲は起きます。
索引の項目意味
pairs_total網内のイオン × 中性。計算対象の全体
no_known_channel反応式が1本も無いペア。DNT+ が存在する理由
resonant対称電荷交換。組成が同じなら構造的に判定。断面積が最大の過程
summary.long_range分極率・双極子・質量が揃い、今すぐ走れるペア
summary.full短距離ポテンシャルも揃い、非弾性・反応チャンネルまで出せるペア
blocked_byそのペアに何が足りないか

入力文書は実行可能なペアにだけ書きます。数千の空スタブを書くと走らせられるものが埋もれるためです。 なお短距離ポテンシャルの取得は DNT+ 側の仕事で、本コードは blocked_by で 足りないことを言うところまでです。

08いま埋まっていないもの

リストの内容として欠けているものはありません。残りはすべて数値です。

  • 振動量子 — V-T の ΔH と振動励起の閾値。振動定数があれば埋まります。
  • 分子の電子励起閾値 — LXCat の手動エクスポート。原子は NIST ASD から自動取得できます。
  • 硫黄フッ化物5種の ΔHf(SF, SF3, SOF, SOF3, SOF4)— 燃焼化学に現れないため既存編纂物に存在しません。
  • 短距離ポテンシャル — DNT+ の入力。本コードの範囲外です。

いずれも gaps.yaml が種と反応を名指しした上で何が足りないかを書いており、 リスト自体は成立しています。

reactgen はネットワークに触れません。取得は acquire、 候補生成は discover の責務で、import-linter が契約として検査しています。
