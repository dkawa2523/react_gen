# 残件と今後の改良計画

2026-11-01更新。対象1.0.0 / schema 5 / CSV形式6。本書は残る作業だけを管理します。
現在の優先順位は、既存の責務・型を使った基盤修正、必要用途の拡張、その後の実データ取得です。
データ不足率を基盤の完成率とせず、実装した責務と用途ごとの検証範囲を示します。
現行仕様は[core_design](core_design.md)、[output_reference](output_reference.md)、
[README](../README.md)、取得と登録は[data_sources](data_sources.md)と
[表記辞書](data_dictionary.md)、個別の科学審査は[scientific_data_review](scientific_data_review.md)を参照してください。

## 実装済み基盤

取得・読込み・照合・採用、独立した科学記録、元ファイルとhash、量ごとの資格は実装済みです。
数値3量に加え、利用するHf/IE/EA/励起量とNASAモデルの出所を量別・対象別に選択できます。
同定・量の適用性と資格を出典順位で昇格せず、元記録と不一致を保持します。
同じ量を別DB・外部形式・ローカル出所から評価する処理は共通です。

欠測、棄却、入力、review、同定、選択、未対応モデルはラベルとtyped workで区別します。
割合は判定・命題・計算ごとの適用対象を分母にし、不成立が決まる同じ命題を欠測として数えません。
補完対象は保存結果の`needs.data_completion`から得られ、派生判定を独立作業へ重複計上しません。

WebBookとCollisionDBの保存形式converter、匿名旧記録の選択用ID、複数ingestの独立記録・queue保持、
保存失敗時の復旧は実装済みです。NASA7原参照の整備・不足fit・中性Hf298導出、出典付きの実断面積を
追加しました。数量と対象・条件・資格は科学審査記録へ置き、追加件数を機構完成度とはしません。

## 直近の境界改修

F1–F8として管理していた原係数・記録ID・数値対象・原記録不変性・status分類・不正参照・
derive保存・共有評価入口の改修を実装しました。取得構造の照合、入力別の文法範囲、
平衡定数の中間演算も見直しました。仕様は現行文書へ統合し、完了条件を別仕様として残しません。
改修後の再レビューと検証記録は[実施記録](reaction_state_generation_implementation_plan.md)へ置きます。

これらは科学記録の意味を保つための改修です。機構の網羅性、任意の構造・準位の生成、
EEDF・表面flux・時間発展の実行を追加した意味ではありません。以下の拡張は引き続き
必要用途と入出力を決めてから設計します。

## 公開配布前の残件

配布前レビューで確認したArrhenius演算、NASA取得対象、旧移行時の関連反応の割当て、
sdist収録漏れと旧説明は修正しました。次は物理モデル追加と別の公開準備です。

| 項目 | 完了条件 |
|---|---|
| Registryを同梱する配布範囲 | 物性の個別数値、原データ集、論文の反応表のまとまった再配布を区別する。Pateau/Sonの集成について包括許諾は未取得で、配布範囲の選択は確認待ち。元データはローカルに保持する |

1.0.0の本体wheel、SHA256SUMS、検証記録をdist/1.0.0へ作成しました。
必要なsourceを含む作業ツリーからbuildし、独立環境で検証した実行ファイル群との一致を確認しています。
版管理対象は今回の変更一式です。ソースのpushとRegistryを含む配布物の確定は別の操作です。
tag作成や外部package公開は実行していません。HEADからsourceを作る際も、配布対象との一致を確認します。

wheelは実行パッケージとschema、sdistはRegistry・台帳・文書・例・検証用fixtureも収録します。
NASA/Cantera・CollisionDB、chemicals・mendeleev/data、NISTの出典noticeを保持しました。
個別の数値事実と原集成の再配布を分けた確認結果は[source policy](source_license_policy.md#10-property-source-review-2026-11-01)と[反応の確認記録](scientific_data_review.md#2026-11-01反応数値の再配布条件と科学適用条件の照合)にあります。
元論文の公開やnoticeの保持を包括的な配布許諾とはしません。
公開範囲と配布条件の選定は、ビルド成功から自動で決まりません。
自作コードへのLICENSE追加は今回不要という利用者の指定に従い、配布前の残件から外しました。
確認内容と検証範囲は[配布前レビュー記録](reaction_state_generation_implementation_plan.md#2026-11-01配布前の最終レビューと旧内容の整理)を参照してください。

## 必要な用途から進める残件

以下は基盤修正後の用途拡張です。すべてを基盤完成の先行条件にしません。
実データ取得は後段に置き、必要な量・モデル・対象・利用条件を先に確定します。

| 項目 | 次の作業と完了条件 |
|---|---|
| 実際に使う複合条件 | 温度・圧力・浴ガス・人口・材料等を必要とするモデルと、その条件評価を一緒に追加。未確認の出典条件と利用者入力を分け、汎用論理式engineを先行実装しない |
| 必要な新熱化学モデル | NASA9・Shomate等を実際に利用する時、正しいCp/H/S式・基準・適用域を追加。NASA7欄への転記や無断再fitをしない。DB別の熱力学判定は作らない |
| 出典情報の補完 | chemicals/mendeleev等の上流record・版・実method、ASDの用途別導出情報を明示資料から回復。package名を科学資格にしない |
| 条件依存する速度表現 | UMISTの加算・区間・代替fitや圧力依存速度則を原定義で区別。必要なモデルだけ共通型と評価式へ追加し、曖昧な重複行を加算しない |
| 根拠の調査範囲 | 存在・反応根拠を限定する利用目的がある時、対象命題と範囲を明示し反対根拠を保持。通常の数値選択の必須入力にはしない |
| 不確かさの統計利用 | confidence・相関が必要な結論で、それらの入力と伝播モデルを追加。転載を独立観測として平均せず、未知相関を独立と仮定しない |
| 物理対象・生成の拡張 | 構造、準位、生成物解像度が必要な用途の入力と生成範囲を設計。化学式だけで構造固有値や状態別分岐を使わず、通常入口にシナリオ・仮条件を足さない |
| 原条件・必要な数値の補充（後段） | 基盤と必要用途の確認後、`rgen needs --data-missing`で対象・量・必要域を絞り、原論文・評価資料・数値表を取得。元の参照・条件・生成物対応を確認し、関連する結論だけを更新する |

## 取得が難しい対象

個別対象・原資料・取得状態・不足理由・次の作業は
[data_supplementation_pending.yaml](../registry/data_notes/data_supplementation_pending.yaml)に保持します。

| 対象区分 | 現在の阻害理由 | 次の扱い |
|---|---|---|
| Pateau係数、自己消光、1977総過程 | 原本文取得403、原条件・状態別生成物が未確認 | 原資料の回復・確認。別の計算値は独立新記録で、元係数の条件確認へ読み替えない |
| UMIST RATE22 | 公式ファイル取得成功、5488行のquote不正で厳格parserが拒否 | 原形式の修正・根拠確認。黙って行を捨てず、原本と修正履歴を保全 |
| NIST総電離の一部ASCII | 取得先500 | 再取得・代替原資料。取得失敗を未収録・現象不存在としない |
| 衝突資料の引用・状態競合 | 引用先不一致、解離continuum等の未同定 | 原資料と物理対象の確認。登録成功から資格を付けない |
| 未測定の分岐・励起・表面量 | 対象に合う量・条件・数値の不足 | 適切な理論計算または測定。総量を分配したり同族ガスの固定値を流用しない |

DBで得られない量の計算は[data_generation_plan](data_generation_plan.md)に分離します。
将来の`data_methods/`配下に計算法ごとの独立packageを置く設計で、現在はsolver・空packageを作りません。
単なる取得失敗、原条件不明、モデル未実装と、新しい量を計算・測定する作業を分けます。

## 用途を決めて追加する計算

| 用途 | 必要情報と返す量 | その処理だけで決まらないこと |
|---|---|---|
| 断面積の分布積分 | 適格曲線、明示分布・規格化・範囲から係数 | EEDFそのもの、機構完成。運動量移行を反応衝突数へ読み替えない |
| EEDF計算 | 衝突セット、混合組成、場・モデル・境界から分布 | 衝突資料の承認、系全体の予測精度 |
| 表面flux | 入射分布・材料・確率からflux、体積源項には幾何量 | 確率だけからのエッチング速度 |
| 時間発展 | 採用機構・速度則・初期値・供給損失・境界から時間依存量 | 数値解による機構・予測精度の承認 |
| 逆速度・参照変換 | 対応する可逆過程・平衡・標準状態、変換前提から目的量 | 非熱平衡への平衡仮定、0 K/有限Tや電子規約の無言補完 |

現在は有界文法、機械生成±1、証拠追加後の第二機械閉包なしという生成範囲です。
品質確認・配布・移行は各変更の完了条件であり、上記全拡張を一括完了の先行条件にはしません。
既存の品質入口は`tools/quality.py quality-pr`。新しい形式・量は同内容の別出所、順序、単位、保存往復で確認します。
data内preferredとv4移行工具は1.xの移行用として保持し、利用者の採用方針の移行・原本保全を確認したうえで2.0で撤去します。
並行writer・停電復旧・性能は必要な運用規模が決まった時に評価し、既存の通常I/O復旧とは分けます。
以前のリリース検証・配布・保全は[実施記録](reaction_state_generation_implementation_plan.md)へ集約します。
