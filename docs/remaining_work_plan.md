# 残件と今後の改良計画

2026-10-12更新。対象：0.7.4 / schema 5。科学判定の命題・適用範囲・具体的不足、量の定義と反応エネルギーの独立資格、CLI・CSV・HTML・不足一覧の共有を実装しました。完了した仕様は[現行責務](core_design.md)、[公開出力](output_reference.md)、[通常利用](../README.md)へ移し、本書は残る作業だけを管理します。個別の根拠・検証は[実施記録](reaction_state_generation_implementation_plan.md)と[科学データ審査](scientific_data_review.md)を参照してください。

## 現在の到達点

共通SourceRef・出典台帳、独立した状態/反応の科学記録、原IDの名前空間と再取得の来歴保存、主張ごとのreview_scope適用、反応主張の直接入力とingest/adoptの往復は実装済みです。純粋な反応主張に空datasetを作らず、未同定の過程を既存チャネルへ推測で合わせません。これらを新規実装の残件には戻しません。下記は、その基盤に残る具体的な境界です。

利用者は現在、速度係数・断面積・sticking確率の数値3量で方法・provider・collectionの優先/限定とrecord固定を指定できます。各記録の資格・量・scope・次数・条件を評価してから選択し、高順位の条件不足と他の適格記録との不一致を残します。Property・NASAの選択と存在/反応根拠の調査範囲は未対応です。record固定は分析全体の量別方針で、指定IDを持たない反応の同量はunavailableになります。

0.7.4のリリース確認と、以前の品質・配布結果は[実施記録](reaction_state_generation_implementation_plan.md)へ集約します。旧schema 5結果は過去の判定として再計算せず読みます。品質確認や配布確認は、全科学データの承認や機構の予測可能性を意味しません。

次は **実際に利用する物性・熱化学モデルのD1選択 → 必要資料の採用・補充** を進めます。比較基準が十分な量は他量の完成を待ちません。C2の複合条件は、その条件を消費する物理モデルとともに実装します。D2は根拠範囲を限定する調査用途で進め、数値選択の必須入力にはしません。取得・科学審査・型への保存・適用評価は別の責務で、全DBの専用APIや全状態の一括審査を先行条件にしません。

NASA7には既に対象・温度域・gas相・明示基準圧と参加種間の共通圧の検査があります。形成量も0.7.3で共通参照型と比較前提の検査を実装しました。残る旧記録の基準・上流資料確認はデータ審査の作業で、比較処理の新設ではありません。C2の残件は実際に使うモデルの複合条件へ絞ります。形成量の表現があること、指定条件で熱化学値を計算できること、種・反応の存在は別の結論です。

各段階は、同じ科学内容を異なるprovider・外部形式・保存経路から与えても、意図した出典選択以外で命題や結果が変わらないことを終了条件にします。必要情報が異なる量や目的は、adapterで無理に同一化せず評価・計算の入出力を分けます。

曲線参照・確率評価と、分布積分・flux変換は必要入力と返す量が違います。現行DataUseは係数利用を中心にしているため、利用者に曲線そのもの・確率そのものを返す入口は、その目的と出力を定める別作業です。EEDF・flux・時間発展の計算を実装済みと扱いません。

Fの文書・schema・移行・統合確認は各変更の完了条件です。通常処理を二重化せず、外部形式adapterと旧内部選択の互換経路を区別します。データ内preferredは未指定量だけの移行用として残り、明示data_selectionがあれば使用しません。0.8で撤去するため、必要な選択を分析入力へ移します。

## 今回完了した範囲と今後の境界

命題の空欄、包括的な不足理由、束縛と安定化の混同、反応energyの親資格による一括扱い、別定義・別対象のエネルギー適用、通常表示の情報欠落と派生不足の重複を修復しました。新規結果は個別scope・必要対象/量/作業・参加状態参照を保存し、旧結果を再判定せず読みます。CSV形式3は個別意味・要件・参照・選択も表示し、旧形式1/2の列とhashを維持します。詳しい仕様を本計画へ重複して残しません。

今後のエネルギーモデルで、incident energyのframe、測定窓、非基底状態、非気相、人口、散逸等を必要とする場合は、当該命題・計算の入力と対応式を一緒に設計します。現在の宣言点・宣言区間の整合を、実験的な絶対限界や現象成立へ広げません。未対応の関係は具体的なモデル不足として返し、追加の物理入力や資料取得だけで実装不足が解消するとは案内しません。

共通Propertyに反応エネルギーの出典・定義・資格・不確かさを保持する基盤は完成しました。confidence・相関を使う統計保証、Property/NASAの明示選択、複合条件を消費する新しいモデルは、それぞれの利用目的に必要な範囲で追加します。全条件の事前必須化、DBごとの判定、表示専用の再判定、汎用診断frameworkを先行実装しません。

## 利用目的を定めて選ぶ拡張

| 拡張 | 必要入力 → 返す結論 | その処理だけでは決まらないこと |
|---|---|---|
| 断面積の分布積分 | 適格曲線、明示分布・規格化・範囲 → 指定分布での係数 | EEDF自体、機構完成。Teから分布を無言で仮定しない |
| EEDF計算 | 衝突セット、場・物理モデル・境界 → モデル内の分布 | 衝突データの承認、系全体の予測精度 |
| 表面flux変換 | 入射分布・粒子・材料条件・確率 → flux。体積源項には幾何量 | 確率だけからのエッチング速度、未指定の表面機構 |
| 時間発展 | 採用機構・速度則・初期値・供給/損失/境界 → 時間依存量 | 数値解による機構・予測精度の承認 |
| 逆速度 | 対応可逆過程・平衡・標準状態 → 適用域内の逆係数 | 非熱平衡への平衡仮定、式だけからの逆対応 |
| 構造・準位・生成範囲 | 明示対象と生成範囲 → 追加候補 | 式だけからの異性体・励起人口・全反応網羅 |

有界文法、±1の機械生成、証拠追加後に機械再閉包しない範囲、候補到達性としての経路図は明示した現行制限です。変更は必要な入力と返す結論を定めた用途拡張として扱います。

各作業では命題と必要入力を定め、規則を一か所で修正し、変更した境界・保存往復・通常利用を確認します。科学判断は一次資料・公式仕様と適用条件を記録し、コード統合時は`tools/quality.py quality-pr`を使います。シナリオ名、特定ガス分岐、仮の物理入力、重複診断で不足を覆いません。
